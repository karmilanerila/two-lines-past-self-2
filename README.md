Entry for the [Two Lines to Your Past Self](https://make.fun/c/u-suga-two-lines-to-your-past-self-f36c83ca?ref=h379tqrk) bounty on make.fun.

`main.py` writes exactly two lines to `/output/entry.txt`: a warning about
one hyper-specific moment — the 1:12 a.m. text to Sara that almost says
"I miss us" — and one sentence on why it mattered, tracing the cause and
effect to the first morning in months without checking her replies.

Run it with:

```sh
python3 main.py
```
